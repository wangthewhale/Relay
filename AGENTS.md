# Relay repository instructions

- Treat GitHub as the source of truth.
- Make implementation changes locally, validate them, and commit them before any Replit deployment.
- Use Replit only as the runtime and deployment target.
- Do not use Replit Agent or the Replit conversation panel to develop or modify this project.
- Keep Relay files, branches, databases, secrets, deployment records, and rollback points separate from FACTA and all other projects.
- Do not publish or create production resources until the user has supplied the product brief and explicitly approved deployment.
